# Голос Шарика — выбор сервиса

**Выбрано (ноябрь 2026): ElevenLabs** — мама подключила, голос проверен, связь с сервером работает.
Запасные файлы без интернета (Silero) — отложены.

Пробная фраза (одна и та же для всех): **«Привет, Лев! Я Шарик. Покажи, где у мальчика нос? Ура! Молодец!»**

Записать образцы сюда автоматически не получилось: каждый сервис отдаёт звук только по ключу (а ключей в репозитории
нет и не должно быть). Поэтому послушать можно бесплатно на страницах самих сервисов — вставить пробную фразу:

| | OpenAI (gpt‑4o‑mini‑tts) | ElevenLabs (Flash v2.5) | Яндекс SpeechKit |
|---|---|---|---|
| Где послушать | https://www.openai.fm — выбрать голос (coral, sage, shimmer…), в поле «Vibe» написать: «добрый весёлый мультяшный щенок, говорит медленно и чётко для маленького ребёнка» | https://elevenlabs.io/app/voice-library — бесплатный аккаунт; поиск «cartoon», «kid», «Russian» | https://yandex.cloud/ru/services/speechkit — «Попробовать» |
| Русский | хороший, иногда лёгкий акцент и ошибки в ударениях | очень естественный | лучший для русского, правильные ударения |
| «Мультяшный» голос | характер задаётся словами (стиль) — можно сделать весёлым щенком | большая библиотека голосов, есть сказочные и мультяшные | несколько дикторов с «радостной» интонацией, мультяшных нет |
| Задержка (ориентир) | ≈ 0,5–1 с | ≈ 0,3–0,6 с | ≈ 0,5–1 с |
| Цена (ориентир, ноябрь 2026) | ≈ $0,015 за минуту звука; одно занятие — около 1–2 минут речи Шарика, т.е. центы | бесплатно до 10 000 знаков в месяц (с указанием авторства, не для продажи); $5 в месяц — 30 000 знаков (Flash — вдвое экономнее) | ≈ 1–1,5 ₽ за 1000 знаков |
| Что нужно | ключ с platform.openai.com (пополнить на $5) | ключ из профиля ElevenLabs | аккаунт Yandex Cloud и оплата российской картой |
| В коде сервера | **готово** (`TTS_PROVIDER=openai`) | **готово** (`TTS_PROVIDER=elevenlabs`) | не подключён — добавлю, если выберете |
| Лицензия звука | звук принадлежит пользователю; правило OpenAI — сообщать, что голос сгенерирован ИИ (мама знает) | на бесплатном тарифе — только некоммерческое использование с указанием ElevenLabs, на платных — без ограничений | звук можно использовать по условиям Yandex Cloud |

Одна и та же фраза синтезируется один раз: дальше она берётся из кэша сервера и телефона, поэтому похвалы и
приветствия почти ничего не стоят.

**Моя рекомендация:** ElevenLabs — самый живой русский и выбор мультяшных голосов; можно начать бесплатно.
Если не понравится или неудобно — OpenAI: один ключ, характер голоса задаётся словами.

**Что нужно от мамы:** послушать, выбрать сервис (и голос), затем по шагу 5б в `cloud/sharik/README.md`
добавить ключ и `TTS_PROVIDER` в Cloudflare. Проверить: «Для взрослых» → раздел «Шарик» → «Проверить голос Шарика».

## Без интернета (запасные файлы)
План — заранее озвучить постоянные фразы (приветствие, похвалы, «играем дальше») открытым синтезом Silero
в файлы `app/voice/`. Варианты модели:
- `v5_cis_base` (русские голоса `ru_…`) — лицензия **MIT** (свободная), но ударения надо расставлять вручную;
- `v5_6_ru` (baya, kseniya, xenia…) — лучше качество и сама ставит ударения, но лицензия **CC BY‑NC** (только некоммерческое).
В облачной сессии запуск модели Silero заблокирован защитой (модель — это исполняемый код из интернета),
поэтому файлы пока не сделаны. Без интернета Шарик говорит голосом телефона, как и раньше.

# ИИ‑Шарик — собеседник, который ведёт занятие

Цель: Шарик (собака из «Речки») сам вовлекает Льва в занятие. Он разговаривает с ним, даёт задания из тех же игр,
что и логопед, видит его через камеру, слышит попытки голоса, хвалит и подстраивает темп.
Родители рядом и наблюдают. Шарик ничего не «оценивает строго»: главное — попытка и вовлечённость.

## Решения (ноябрь 2026, мама)

| Вопрос | Решение |
|---|---|
| Интернет | Можно: ИИ‑части работают с интернетом. Старые игры — по‑прежнему без него. |
| Распознавание речи | Строго не нужно. Засчитываем попытку (был голос, был звук, был жест). Слова при желании показываем родителю, но Льва не поправляем по ним. |
| Приватность | Допустимо отправлять в облако то, что нужно для работы. Видео с камеры всё равно обрабатывается на телефоне — так быстрее и бесплатно. |
| Безопасность разговора | Занятия только при родителях. Шарик говорит строго в рамках утверждённых заданий. |
| Деньги и ключи | Платим за нужные сервисы. Ключи хранятся только на своём маленьком сервере (не в приложении и не в репозитории). |
| Задания | Только из утверждённого списка — `TASKS.md`. |
| Правило из CLAUDE.md «речь не распознаётся и не оценивается» | Остаётся в силе для оценки: речь не оценивается. Для ИИ‑Шарика допускается слушать голос, чтобы поддерживать разговор. |

## Три шага

### Шаг 1. Камера на телефоне — «Зеркало с Шариком» (сделан в версии 30)
- Артикуляционная гимнастика: улыбка, трубочка, «а‑а‑а», надуть щёки, закрыть глазки, удивиться (брови).
- «Покажи на себе»: нос, рот, глаз, ушко, щёчка, рука на голове.
- Как работает: MediaPipe (Google, бесплатно, Apache‑2.0) прямо в браузере телефона
  находит лицо (478 точек и 52 «выражения») и руки (21 точка на каждой руке). Поза держится полсекунды — похвала.
- Кнопка «Получилось ✓» для мамы всегда есть. Без камеры игра работает только с ней.
- Файлы: `app/vendor/mediapipe/` (около 25 МБ, загружаются один раз при первом входе в игру).
  Код — функция `mirrRound` в `app/js/5-mirror.js`, пороги — в `MIRR_CFG`, задания — в `MIRR_EX`.
- Что проверить на телефоне: насколько легко Льву «попасть» в позу. Если слишком трудно или слишком легко,
  поменять числа в `MIRR_CFG` и `MIRR_EX` (например, `mouthPucker>.6` → `.5`).

### Шаг 2. Живой голос Шарика (версия 37, ждёт выбора голоса)
Реплики «Занятия с Шариком» озвучиваются облачным голосом через свой сервер (`/tts`, тот же семейный код).
- Порядок: записи мамы (свой голос) → облачный голос → голос телефона. Если сервер не прислал звук за 3,5 с,
  нет интернета или голос не настроен — Шарик говорит голосом телефона, занятие не ждёт.
- Объёмный Шарик открывает рот, только когда звук действительно зазвучал, и двигает ртом по громкости голоса;
  в паузах рот закрыт. Слушать Льва Шарик начинает только после настоящего конца фразы (иначе услышит себя).
- Одинаковые фразы синтезируются один раз: дальше они берутся из кэша сервера и из памяти телефона.
- Выключатель «Живой голос Шарика» в «Для взрослых». Там же видно, за сколько Шарик отвечает
  (от конца задания до первого звука — модель + голос + сеть); эти цифры записать в раздел «Проба».
- Выбор сервиса: `docs/ai-sharik/voices/README.md` (сравнение, образцы и что нужно от мамы).
- Запасные файлы без интернета (Silero) пока не сделаны: см. там же, раздел «Без интернета».

### Шаг 3. Шарик‑собеседник (ИИ)
Как устроено:

```
Телефон (Речка)                        Свой сервер (Cloudflare Worker, бесплатный тариф)      Облачные сервисы
 ├─ камера → MediaPipe (на телефоне)    ├─ хранит ключи                                      ├─ языковая модель (Claude)
 ├─ микрофон → громкость / речь  ──────▶├─ /sharik  — «что сказать и какое задание дальше» ──▶├─ распознавание речи
 ├─ игры «Речки» (задания)       ◀──────├─ /tts     — голос Шарика                          ──▶└─ синтез голоса
 └─ кнопки для мамы                     └─ счётчик запросов в день (только с KV, см. ниже)
```

- Приложение отправляет на сервер короткое описание момента: «задание: Покажи, где нос; Лев показал правильно со
  второй попытки; был голос 1,2 с; уровень 2». Сервер спрашивает модель и возвращает реплику Шарика и следующий шаг
  (какую игру и задание включить). Видео и фото не отправляются.
- Шарик выбирает задания только из `TASKS.md`. Темп и похвалу подстраивает под Льва:
  если устал — короче задания и больше похвалы, если увлёкся — следующий уровень.
- Распознанные слова (если включим распознавание) идут только в подсказку для мамы и в журнал для логопеда,
  а не в оценку.
- Кнопки для мамы: «Пауза», «Хватит на сегодня», «Засчитать», «Повтори».
- Выключается в разделе для взрослых. Без интернета приложение работает как сейчас, просто без Шарика‑собеседника.

Модель: сейчас сервер по умолчанию работает на Claude Opus 5.5 (`claude-opus-5-5`, настройка `MODEL`).
Для живого разговора важна скорость ответа, поэтому на пробе сравним её с быстрой и примерно в 40 раз более дешёвой
Claude Haiku 5.5 (`claude-haiku-5-5`, $0,10 / $0,50 за миллион токенов против $4 / $20 у Opus 5.5 — цены ноября 2026,
перед выбором проверить на https://www.anthropic.com/pricing). Сравниваем одинаковые короткие занятия: насколько естественны
реплики, соблюдает ли Шарик правила, сколько секунд от конца задания до первого звука, сколько стоит.
Сама по себе более сильная модель не делает голос и движения Шарика лучше.

Примерная стоимость (оценка, уточним по факту пробы): одно занятие — примерно 20–60 запросов к модели
(после каждого задания и после каждой попытки Льва сказать). На Haiku 5.5 это доли цента, на Opus 5.5 — несколько центов.
Голос (синтез и распознавание) — отдельные расходы, зависят от сервиса.

**Как ограничены расходы — честно.** Счётчик «не больше N запросов в день» (`DAILY_LIMIT`, `STT_LIMIT`) работает,
только если к серверу подключено хранилище KV (запуск через терминал, вариант Б). При запуске через браузер (вариант А)
счётчика нет, и **единственная защита — месячный лимит расходов в консоли Anthropic** (Settings → Limits) —
его обязательно поставить. Счётчик запросов — не денежный предел: он считает обращения, а не доллары.
Любой новый платный маршрут сервера (например, `/tts`) закрывается тем же семейным кодом, что `/sharik` и `/stt`.

### Шаг 3б. Шарик слышит Льва (сделан в версии 32)
- После каждой своей реплики Шарик 3 секунды слушает (значок уха и полоска громкости). Если Лев издал звук или слово —
  сразу звучит радостный сигнал, Шарик подпрыгивает, а сервер получает событие `voice` с длительностью голоса,
  и Шарик отвечает на попытку («Ух ты, ты сказал!»). Засчитывается сама попытка; точность не оценивается никогда.
  Если Лев молчит — занятие идёт дальше как обычно. Нажатие на экран — не ждать.
- Выключатели в «Для взрослых»: «Шарик слушает голос» (по умолчанию включено; только громкость, как в голосовых играх)
  и «Распознавать слова через сервер» (по умолчанию выключено). Без микрофона занятие идёт без слушания.
- Если распознавание включено: короткая запись (до 6 с) уходит на свой сервер (`/stt`), текст показывается маме мелко
  внизу экрана («Маме: слышно «нос» (не оценивается)») и передаётся Шарику в поле `heard` — чтобы он мог повторить слово
  как образец. Шарику запрещено поправлять Льва по этому тексту. Запись нигде не сохраняется.

**Какое распознавание выбрано и почему.** Надёжно распознавать речь ребёнка с алалией не умеет ни один сервис:
слова короткие, звуки неточные, Whisper‑подобные модели на тишине «додумывают» фразы. Поэтому текст — только подсказка.

| Вариант | Русский, детская речь | Цена (ориентир, ноябрь 2026) | Что нужно настроить |
|---|---|---|---|
| **Whisper large‑v3‑turbo на Cloudflare Workers AI** — выбран | хорошо для взрослых, для детской речи средне; на тишине выдумывает фразы (сервер их отбрасывает) | ≈ $0,0005 за минуту, есть бесплатная дневная квота — на занятия хватает | одна привязка `AI` в том же сервере, нового ключа и аккаунта не нужно |
| OpenAI gpt‑4o‑transcribe / mini | немного точнее на шумной и нечёткой речи | ≈ $0,003–0,006 за минуту | ещё один аккаунт и ключ |
| Яндекс SpeechKit | лучший для русского языка | недорого | аккаунт Yandex Cloud и оплата — из‑за границы бывает сложно |
| Google Speech‑to‑Text (Chirp) | хороший русский | ≈ $0,016 за минуту | аккаунт Google Cloud, сложная настройка |
| Распознавание на телефоне (Web Speech API, Vosk) | слабо для детской речи; Web Speech в APK работает ненадёжно | бесплатно | — |

Если на пробе Whisper будет часто ошибаться, можно добавить OpenAI как второй вариант в `cloud/sharik/src/stt.ts`.

### Объёмный Шарик (версия 33)
Вместо плоского рисунка — объёмный (3D) мультяшный Шарик: моргает, дышит, виляет хвостом, уши качаются.
- «Занятие с Шариком»: настроение по ответу сервера (`tone`): радуется — прыгает, приглашает — машет лапой,
  утешает — гладит лапой и наклоняет голову, слушает — наклоняет голову и поднимает ухо. Пока говорит — двигается рот.
- «Повторяй за Шариком»: мордочка крупно, рот показывает каждый звук (а, о, у, и, м) — как раньше на рисунке, только объёмно.
- «Зеркало с Шариком»: Шарик сам показывает упражнение (улыбка, трубочка, «а‑а‑а», щёчки, глазки, брови)
  и «покажи на себе» — тянет лапу к носу, рту, глазу, щёчке, уху, голове.
- Почему так, а не готовая модель: готовые 3D‑собаки со свободной лицензией не умеют говорить ртом и показывать
  упражнения; рисованные 2D‑персонажи (Rive, Lottie) требуют художника и отдельного редактора. Здесь персонаж собран
  кодом из простых фигур на свободной библиотеке three.js (MIT), его можно менять без художника.
- Выключатель «Объёмный Шарик» в «Для взрослых» (по умолчанию включён). Если телефон не умеет 3D (WebGL) или
  тормозит — выключить, вернётся прежний рисунок. Подробности — `app/vendor/sharik3d/README.md`.
- Что проверить на телефоне: плавно ли двигается (нет ли рывков), нравится ли Льву, понятен ли рот в «Повторяй».

### Память между занятиями (версия 34)
- Перед занятием телефон сам считает по журналу игр короткую сводку за 7 дней: сколько дней занимались, какие игры
  и как (сколько с первой попытки, уровень был → стал), что трудно (например, «ухо» не сразу 3 раза из 4) и что стало получаться.
- Сводка уходит на сервер вместе с каждым запросом, сервер подставляет её в подсказку модели и **нигде не хранит**.
  Имени и личных данных в ней нет — только названия игр и слов-заданий.
- Шарик вспоминает приятное на старте, иногда предлагает повторить трудное и хвалит за прогресс:
  «Вчера ушко было трудно, а сегодня — получилось!». За прошлые ошибки не упрекает.
- Выключатель «Шарик помнит прошлые занятия» в «Для взрослых» (по умолчанию включён). Код — `shMemory` в `app/js/6-sharik.js`,
  на сервере — `memoryText` в `cloud/sharik/src/sharik.ts`.

### Камера: всё тело и движения (версия 35)
- «Зеркало», уровень 4: «покажи живот, ногу, коленку», «руки на плечи», «помаши», «хлопни в ладоши», «руки вверх», «присядь».
  Работает модель позы MediaPipe Pose (33 точки тела, на телефоне, видео никуда не уходит). Объёмный Шарик показывает каждое движение.
- Телефон надо поставить подальше (на 1,5–2 м), чтобы Лев был виден целиком; если тела не видно 4 секунды —
  Шарик просит: «Отойди чуть подальше…». Кнопка «Получилось» для мамы, как всегда, работает.
- «Смотрит ли на экран»: если в «Занятии с Шариком» во время «Зеркала» Лев отвернулся или ушёл из кадра дольше 5 секунд,
  сервер получает событие `silence`, и Шарик зовёт его по имени (не больше двух раз за задание).
- Пороги — в `MIRR_CFG` (`belly`, `knee`, `shoulder`, `waveAmp`, `clapNear`, `squatDeg`, `lookOff`, `away` …),
  код — `mirrBody`, `mirrLook` в `app/js/5-mirror.js`. Выключатель уровня 4 — в «Для взрослых».
- Что проверить дома: на каком расстоянии ставить телефон, легко ли «засчитывается» каждое движение.

## Что нужно от родителей для шага 3
1. Аккаунт Cloudflare (бесплатный) — там будет жить маленький сервер Шарика. Код сервера будет в `cloud/sharik/`.
2. Ключ API Anthropic (console.anthropic.com) с небольшим пополнением и месячным лимитом.
3. Ключ сервиса голоса (выберем по образцам).
4. Утвердить `TASKS.md`.
Ключи вносятся в настройки Cloudflare (Secrets), в репозиторий и в приложение они не попадают.

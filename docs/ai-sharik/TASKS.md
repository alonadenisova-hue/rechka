# Задания для ИИ‑Шарика — ЧЕРНОВИК на утверждение

Как утверждать: поставьте ✅ или ❌ в колонке «Да?», допишите замечания. Шарик будет давать только задания с ✅.
Можно добавить свои строки — например, из тетради логопеда.

Как отвечает Лев:
- **нажатие** — на картинку в игре;
- **камера** — поза или жест (видео обрабатывается на телефоне);
- **голос** — любая попытка сказать: засчитывается сам голос, а не точность слова;
- **мама** — кнопка «Засчитать».

## 1. Артикуляционная гимнастика (камера, «Зеркало с Шариком»)

| Да? | Задание | Что говорит Шарик | Как засчитывается |
|---|---|---|---|
| | Улыбка («Заборчик») | «Улыбнись широко, как я!» | камера: улыбка держится полсекунды |
| | Трубочка | «Вытяни губы трубочкой!» | камера: губы трубочкой |
| | «А‑а‑а» (рот широко) | «Открой рот широко: а‑а‑а!» | камера: рот открыт; голос: звук «а» |
| | Щёчки‑шарики | «Надуй щёчки!» | камера |
| | Закрой глазки | «Закрой глазки!» | камера |
| | Удивись (брови) | «Подними брови, удивись!» | камера |
| | Улыбка → трубочка (чередование) | «Улыбка! Трубочка! Улыбка!» | камера, 3 смены подряд |
| | Язычок‑лопаточка, часики, качели | — | ⚠ камера не видит язык надёжно → только кнопка мамы |

| | Покажи нос / рот / глаз / ушко / щёчку | «Покажи, где твой нос!» | камера: палец у носа |

## 4. Разговор между заданиями (голос — попытка)

| Да? | Ситуация | Что говорит Шарик |
|---|---|---|
| | Начало | «Привет, Лев! Я Шарик. Будем играть?» |
| | Ответил правильно | короткая похвала + повтор слова: «Да! Это нос!» |
| | Ошибся | «Ой, это ухо. А где нос?» + подсказка после 2 ошибок |
| | Молчит или отвлёкся | позвать по имени, повторить, показать подсказку |
| | Устал (много ошибок, долго молчит) | «Давай отдохнём! Поиграем в шарики?» — игра‑награда |
| | Конец (20–30 минут или по кнопке мамы) | «Ты молодец! Завтра ещё поиграем!» + пазл |

## 5. Вопросы к маме и логопеду
- Длительность занятия с Шариком: 15, 20 или 30 минут?
- Сколько раз повторять одно задание, если не получается (сейчас — подсказка после 2 ошибок)?
- Какие звуки и слоги сейчас в работе у логопеда (для «Повторяй за Шариком»)?
- Нужно ли Шарику называть Льва по имени? Какие ласковые слова использовать, а каких избегать?

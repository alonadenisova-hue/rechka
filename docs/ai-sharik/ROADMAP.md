# ИИ‑Шарик — очередь задач

Как пользоваться: берите **первую невыполненную** задачу, открывайте **новый чат** (облако, репозиторий `rechka`)
и вставляйте текст из блока целиком. Одна задача — один чат. Задачи, которые меняют `app/index.html`,
делаем **по очереди**: параллельно они мешают друг другу. Параллельно можно только задачи с пометкой «🟢 можно параллельно».

Каждый чат в конце сам: проверяет (как написано в `CLAUDE.md`), сливает PR в `main`, отмечает задачу здесь ✅
и присылает архив `app/` для сайта.

Общий контекст для всех задач уже в репозитории: `CLAUDE.md`, `docs/ai-sharik/README.md`, `docs/ai-sharik/TASKS.md`,
`cloud/sharik/README.md`.

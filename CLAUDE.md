# Речка — памятка для агента

«Речка» — веб-приложение (PWA) для Android: речевые игры для Льва (5,5 лет, сенсомоторная алалия)
по материалам его логопеда. На телефоне — APK (PWABuilder), который берёт сайт (Netlify; с ноября 2026 есть копия на Cloudflare Pages):
обновили сайт — APK подхватывает сам. Работает без интернета, всё хранится на телефоне.

## Главное
- `app/` — само приложение в том виде, как оно выкладывается на сайт. Правки вносятся прямо здесь.
  - `app/index.html` — разметка и стили; код — `app/js/1-core.js … 8-parent.js` (обычные `<script>`, подключаются по порядку
    и делят общие переменные; функции из более поздних файлов можно вызывать только после загрузки страницы):
    1 основа и движок игр, 2–4 игры, 5 «Зеркало», 6 «Занятие с Шариком», 7 голосовые игры, видео, «Хочу»,
    8 главный экран, раздел для взрослых, запуск и таблица игр `ROUNDS`. Новый файл — добавить в `index.html` и в `sw.js`.
  - `app/sw.js` — офлайн-кэш (service worker); `app/manifest.webmanifest`.
  - `app/data*.js`, `app/sounds*.js` — картинки и голоса, встроенные как base64; `app/img*/`, `app/anim*/` — файлы картинок.
  - `app/data11.js` — подсказки «Сегодня дома»; `app/data14.js` — фото пазлов и их лицензии.
- `audio-raw/` — полные исходные записи голосов животных (белка, ёж, мышь в приложение ещё не вошли), см. `audio-raw/README.md`.
- `reference/source-v28/` — исходники сборки версии 28 (код по версиям, скрипты сборки); только для справки.
- В репозитории версия 36 (кэш `rechka-v36`, внизу главного экрана написано «версия 36»).
- Проект «ИИ‑Шарик» (собеседник с камерой и голосом): план, решения — `docs/ai-sharik/README.md`,
  очередь задач (одна задача — один чат, по порядку) — `docs/ai-sharik/ROADMAP.md`,
  задания — `docs/ai-sharik/TASKS.md` (Шарик даёт только утверждённые). Камера: `app/vendor/mediapipe/` (на телефоне).
  Сервер Шарика — `cloud/sharik/` (Cloudflare Worker + Claude; проверки: `npm run check`, `npm test`; запуск — его README).
  После правок в `cloud/sharik/src/` выполнить `npm run bundle` и закоммитить `web/sharik-worker.js` — мама вставляет его в Cloudflare через браузер.
  Режим «Занятие с Шариком» в приложении — `shStep`/`startSharik` в `app/js/6-sharik.js`, включается в «Для взрослых».
  Объёмный Шарик (3D, three.js): `app/vendor/sharik3d/sharik3d.js` собирается из `tools/sharik3d/sharik3d.src.js`
  (`cd tools/sharik3d && npm install && npm run build`); в `app/js/3-games-b.js` — `sh3`/`s3`, выключатель «Объёмный Шарик».
- Проверка после правок: `python3 tools/audit.py --only ui` — игры открываются, нет ошибок консоли.
- Автотест всех игр на всех уровнях: `cd app && python3 -m http.server 8765` в фоне, затем
  `python3 tools/test.py nomic` и `python3 tools/test.py mic` (≈10 минут каждый; итог в последней строке).
- Аудит качества: см. `AUDIT.md` («Проведи аудит по AUDIT.md»).
- После любой правки в `app/` поднять версию кэша в `app/sw.js` и номер «версия N» внизу главного экрана в `app/index.html`.
  Задачи, которые меняют разные файлы `app/js/`, можно делать параллельно.
  `index.html` и `*.js` service worker берёт сначала из сети, поэтому телефон с интернетом видит новую версию со второго открытия.

## Правила
- Речь Льва не распознаётся и не оценивается. Микрофон — только громкость.
  Исключение (решение мамы, ноябрь 2026): ИИ‑Шарик может слушать голос, чтобы поддерживать разговор, но засчитывает только попытку, не точность.
- Без микрофона и камеры приложение должно работать полностью.
- Мгновенная похвала после верного ответа обязательна.
- Не ломать сохранённые на телефоне данные (IndexedDB): голос, фото, видео, статистика.
- Каждая новая функция отключается в разделе для взрослых.
- Новые картинки и звуки — только со свободной лицензией, источник записать.
- Методику и содержание игр не менять без согласия: предлагать в отчёте.
- Отвечать и писать отчёты по-русски, простыми словами (читает мама, не программист).

## Выпуск
- PR в `main` агент сливает сам, если проверки пройдены (`tools/audit.py --only ui`: все игры открываются, ошибок консоли нет) — так попросила мама.
Папку `app/` перетаскивают в Deploys сайта на Netlify (или в «Create new deployment» на Cloudflare Pages) вручную.
Токенов Netlify и Cloudflare в репозитории нет и не должно быть.

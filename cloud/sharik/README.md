# Сервер ИИ‑Шарика

Маленькая программа на Cloudflare Workers. Через неё приложение «Речка» разговаривает с ИИ (Claude):
приложение рассказывает, что происходит на занятии, а Шарик отвечает, что сказать и какую игру включить дальше.
Ключи хранятся только здесь, в секретах Cloudflare, — не в приложении и не в репозитории.

План и решения — в `docs/ai-sharik/README.md`, задания — в `docs/ai-sharik/TASKS.md`
(в коде сервера — `src/tasks.ts`; у отклонённых заданий поставить `on: false`).

## Как запустить — вариант А: всё в браузере, без терминала (~10 минут)

Подходит, если вы не программист. Нужен компьютер с браузером (с телефона неудобно: придётся копировать большой файл).

1. **Ключ Anthropic.** На https://console.anthropic.com → Settings → API Keys создать ключ и сразу скопировать его
   (потом его не показывают целиком). Пополнить баланс на небольшую сумму, в Settings → Limits поставить месячный лимит.
2. **Аккаунт Cloudflare** (бесплатный): https://dash.cloudflare.com/sign-up, подтвердить почту.
3. **Создать сервер.** В панели Cloudflare слева: **Compute (Workers)** → **Workers & Pages** →
   кнопка **Create** → **Start with Hello World!** (или «Create Worker»). Имя: `rechka-sharik` → **Deploy**.
4. **Вставить код Шарика.**
   - Откройте файл кода: https://github.com/alonadenisova-hue/rechka/blob/main/cloud/sharik/web/sharik-worker.js
     и нажмите справа вверху кнопку **Copy raw file** (значок двух квадратиков) — весь код скопируется.
   - В Cloudflare на странице сервера нажмите **Edit code**. Слева откроется файл `worker.js` с примером.
     Выделите в нём всё (Ctrl+A, на Mac — Cmd+A), удалите и вставьте скопированное (Ctrl+V / Cmd+V).
   - Нажмите **Deploy** справа вверху.
5. **Секреты.** Вернитесь на страницу сервера → вкладка **Settings** → **Variables and Secrets** → **Add**:
   - Type: **Secret**, Variable name: `ANTHROPIC_API_KEY`, Value: ваш ключ Anthropic → **Deploy**/**Save**;
   - ещё раз **Add**: Type: **Secret**, Variable name: `SHARIK_CODE`, Value: «семейный код» — любое слово или число,
     например `lev-2026` (его же потом впишете в приложении).
   - По желанию ещё одна, Type: **Text**, Variable name: `ALLOWED_ORIGINS`, Value: адрес сайта «Речки»
     (например `https://rechka.netlify.app`) — тогда сервер будет отвечать только вашему сайту.
5а. **Распознавание слов (по желанию).** Нужно, только если в приложении включите «Распознавать слова».
   На странице сервера → **Settings** → **Bindings** → **Add** → **Workers AI** → Variable name: `AI` → **Deploy**/**Save**.
   Отдельный ключ не нужен: бесплатной дневной квоты Cloudflare хватает на занятия.
5б. **Живой голос Шарика (по желанию).** Без этого шага Шарик говорит голосом телефона, как раньше.
   Settings → Variables and Secrets → Add — один из двух вариантов (какой лучше — см. `docs/ai-sharik/voices/README.md`):
   - **OpenAI:** Type **Secret**, имя `OPENAI_API_KEY`, значение — ключ с https://platform.openai.com/api-keys;
     Type **Text**, имя `TTS_PROVIDER`, значение `openai`. По желанию Text `TTS_VOICE` (например `coral`, `sage`, `shimmer`).
   - **ElevenLabs:** Type **Secret**, имя `ELEVENLABS_API_KEY`, значение — ключ с https://elevenlabs.io (Profile → API keys);
     Type **Text**, `TTS_PROVIDER` = `elevenlabs`, `TTS_VOICE` = id выбранного голоса (в библиотеке голосов: «⋯» → Copy voice ID).
   Одинаковые фразы синтезируются один раз и дальше берутся из кэша Cloudflare (бесплатно).
5в. **Память голоса и дневной лимит (советую, ~2 минуты).** Записанный голос фраз хранится надёжно и второй раз
   не оплачивается; заодно включается счётчик «дневного лимита».
   - В панели Cloudflare слева: **Storage & Databases** → **KV** → **Create** (или «Create namespace»), имя `rechka-sharik` → **Add**/**Create**.
   - Страница сервера → **Settings** → **Bindings** → **Add** → **KV namespace** → Variable name: `USAGE`,
     KV namespace: `rechka-sharik` → **Deploy**/**Save**.
   Бесплатно: до 1 ГБ и 1000 записей в день — на занятия хватает.
6. **Проверка.** На странице сервера вверху есть адрес вида `https://rechka-sharik.<имя>.workers.dev`.
   Откройте в браузере этот адрес с `/health` на конце. Должно появиться `{"ok":true,…,"key":true,"stt":true}`
   (`"stt":false` — нет привязки Workers AI из шага 5а; без неё всё работает, только слова не распознаются;
   `"tts":"openai"` или `"elevenlabs"` — живой голос включён, `"tts":false` — нет, Шарик говорит голосом телефона;
   `"kv":true` — память голоса и дневной лимит включены (шаг 5в)).
7а. **Готовые фразы на телефон:** «Для взрослых» → раздел «Шарик» → «Скачать постоянные фразы» (один раз, при интернете).
   Похвалы, приветствия и прощания дальше звучат с телефона — без оплаты и даже без интернета.
   Если `"key":false` — ключ Anthropic не сохранился, повторите шаг 5.
7. **В приложении:** «Для взрослых» (подержать шестерёнку 2 секунды) → раздел «Шарик» → «Занятие с Шариком» — включить, вписать адрес сервера (без `/health`)
   и семейный код. На главном экране появится кнопка «Занятие с Шариком».

Названия кнопок у Cloudflare иногда меняются — если что-то не находится, пришлите скриншот в чат.
Без шага 5в нет счётчика «дневного лимита» на сервере — расходы ограничивает месячный лимит в консоли Anthropic.
Когда код сервера обновится, повторить шаг 4 (скопировать новый файл и нажать Deploy); секреты сохраняются.

## Как запустить — вариант Б: через терминал (для тех, кто привык)

Нужен компьютер с Node.js 22 или новее (https://nodejs.org) и копия репозитория.

1. Шаги 1–2 из варианта А.
2. В терминале, в папке `cloud/sharik` репозитория:
   ```bash
   npm install
   ```
   ```bash
   npx wrangler login
   ```
   ```bash
   npx wrangler kv namespace create USAGE
   ```
   Последняя команда напечатает `id = "…"` — вписать его в `wrangler.toml` в блок `[[kv_namespaces]]`
   и убрать `#` в начале трёх строк этого блока (это счётчик, который не даст потратить больше дневного лимита).
3. Секреты (каждая команда спросит значение — вставить и нажать Enter):
   ```bash
   npx wrangler secret put ANTHROPIC_API_KEY
   ```
   ```bash
   npx wrangler secret put SHARIK_CODE
   ```
4. В `wrangler.toml` в `ALLOWED_ORIGINS` вписать адрес сайта «Речки».
5. Выложить:
   ```bash
   npx wrangler deploy
   ```
6. Шаги 6–7 из варианта А.

## Настройки

В варианте А — переменные типа Text в Settings → Variables and Secrets; в варианте Б — `wrangler.toml`, раздел `[vars]`.
Все необязательны: без них действуют значения по умолчанию.

| Настройка | Что значит | По умолчанию |
|---|---|---|
| `MODEL` | модель Claude | `claude-opus-5-5` |
| `EFFORT` | насколько долго модель думает: `low` быстрее, `high` вдумчивее | `low` |
| `DAILY_LIMIT` | сколько обращений к модели в сутки (одно занятие — примерно 20–60) | `600` |
| `STT_LIMIT` | сколько распознаваний голоса в сутки (только при счётчике KV) | `400` |
| `TTS_PROVIDER` | сервис голоса: `openai` или `elevenlabs` (нужен ключ, шаг 5б) | пусто — голос телефона |
| `TTS_VOICE` | голос: у OpenAI имя (`coral`, `sage`…), у ElevenLabs — id голоса | `coral` / «Charlie» |
| `TTS_MODEL` | модель синтеза | `gpt-4o-mini-tts` / `eleven_flash_v2_5` |
| `TTS_STYLE` | только OpenAI: как говорить (по-русски словами) | «добрый весёлый мультяшный щенок…» |
| `TTS_LIMIT` | сколько новых фраз в сутки синтезировать (только при счётчике KV; из кэша — без счёта) | `800` |
| `ALLOWED_ORIGINS` | с каких сайтов можно обращаться к серверу | пусто (с любых — только для проверки) |

Если ответы Шарика приходят слишком медленно (Лев успевает отвлечься), можно попробовать более быструю
модель: `MODEL = "claude-haiku-5-5"` — она заметно дешевле, но реплики могут быть проще. Сравним на пробе.

Посмотреть, что происходит на сервере (время ответа, ошибки), можно командой `npx wrangler tail`.

## Что если что-то сломалось
Приложение никогда не «зависает» из‑за сервера: если сервер недоступен, ключ неверный, кончился лимит
или модель ответила не по правилам, Шарик говорит короткую похвалу сам, а игры выбираются по кругу.
В ответе сервера поле `note` подсказывает причину: `ok`, `no_key`, `bad_key`, `daily_limit`, `refusal`,
`bad_json`, `rate_limited`, `connection`, `api_NNN`.

## Для разработчика
- `src/index.ts` — сервер (маршруты `/sharik`, `/stt` и `/health`, семейный код, лимит, обращение к Claude).
- `src/sharik.ts` — инструкция для модели, разбор запроса, проверка ответа (только игры из каталога).
- `src/tasks.ts` — каталог заданий.
- `src/phrases.ts` — готовые фразы Шарика (модель берёт их дословно; приложение заранее скачивает их голос через `GET /phrases`).
- `src/tts.ts` — голос Шарика для `/tts` (OpenAI или ElevenLabs), очистка текста, ключ кэша.
- `src/stt.ts` — распознавание речи для `/stt` (Whisper на Workers AI) и фильтр «выдуманных» фраз.
- Проверки: `npm run check` (типы), `npm test` (логика).
- **После любой правки в `src/` выполнить `npm run bundle`** — пересобирает `web/sharik-worker.js` (файл для варианта А) и закоммитить его.
  Весь сервер без ключа: `node test/mock-anthropic.mjs` (поддельный API на порту 8789), в `.dev.vars` —
  `ANTHROPIC_API_KEY=test`, `ANTHROPIC_BASE_URL=http://127.0.0.1:8789`, `SHARIK_CODE=1234`, затем `npx wrangler dev`;
  сценарий ответа задаётся в `test/scenario.txt` (`ok`, `refusal`, `garbage`, `error`, `badkey`, `wronggame`).

### Запрос приложения (`POST /sharik`, заголовок `X-Sharik-Code`)
```json
{"child":{"name":"Лев"},"minutes":3,"plannedMinutes":20,"levels":{"body":1},
 "available":["body","mirr","bal"],"history":[{"who":"sharik","text":"Покажи, где нос!"}],
 "event":{"type":"result","game":"body","task":"Покажи, где нос","ok":true,"attempts":1,"how":"tap"}}
```
Необязательное поле `memory` — сводка прошлых занятий за 7 дней (считается на телефоне, сервер её не хранит):
`{"days":3,"lastDaysAgo":1,"games":[{"game":"body","rounds":12,"first":8,"lvFrom":1,"lvNow":2}],
"hard":[{"game":"body","item":"ухо","tries":4,"misses":3,"daysAgo":1}],"better":[{"game":"body","item":"нос","daysAgo":1}]}`.

`event.type`: `start`, `result`, `silence`, `voice`, `tired`, `parent_end`, `parent_pause`.
Голос Льва (Шарик послушал после своей реплики): `{"type":"voice","game":"body","voiceMs":900,"heard":"нос"}` —
`game` — игра, которую Шарик собирался включить, `heard` — только если мама включила распознавание.

### Распознавание (`POST /stt`, заголовок `X-Sharik-Code`)
Тело — WAV (моно, 16 кГц, до 6 с; до 400 КБ). Ответ: `{"text":"нос","note":"ok"}`.
`note`: `ok`, `empty` (ничего не разобрано или «выдумка» Whisper), `no_ai` (нет привязки AI), `daily_limit`, `error`.
Текст — только подсказка для мамы и поле `heard` в событии `voice`; речь Льва не оценивается.

### Голос (`POST /tts`, заголовок `X-Sharik-Code`)
Тело `{"text":"Привет, Лев!"}` (до 300 символов; приложение присылает по одному предложению, готовые фразы
приводятся к записанному виду). Голос ищется в кэше Cloudflare, потом в KV (`USAGE`, ключ `tts:…`, фразы до 120 знаков),
и только потом заказывается у сервиса. Ответ — `audio/mpeg` (заголовок `X-Tts-Cache: hit|miss`).
Если голос не настроен или сервис не ответил — код 503 и `{"note":"no_tts"|"bad_key"|"timeout"|"rate_limited"|"daily_limit"|"api_NNN"|"connection"}`:
приложение тогда говорит голосом телефона. Проверка без ключей: в `.dev.vars` ещё `TTS_PROVIDER=openai`, `OPENAI_API_KEY=test`,
`OPENAI_BASE_URL=http://127.0.0.1:8789` (поддельный API `test/mock-anthropic.mjs` отвечает и на синтез).

### Ответ
```json
{"say":"Да! Это нос! А теперь улыбнись!","next":{"kind":"game","game":"mirr","level":1},"tone":"praise","note":"ok"}
```
`next.kind`: `game`, `break` (игра‑перерыв), `wait`, `end`.
